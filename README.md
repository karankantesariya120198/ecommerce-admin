<h1>📦 E-commerce Admin Panel</h1>

<p>
  Full-stack <b>E-commerce Admin Panel</b> built with <b>React</b> (frontend) and <b>Node.js/Express</b> (backend).<br>
  This system allows admins to manage products, orders, users, and reports efficiently.
</p>

<h2>🚀 Features</h2>
<ul>
  <li>🔑 Authentication & Authorization (Admin login, JWT-based)</li>
  <li>📦 Product Management (CRUD for products, categories, inventory)</li>
  <li>🛒 Order Management (track orders, update status)</li>
  <li>👥 User Management (view, edit, block/unblock users)</li>
  <li>📊 Dashboard & Reports (sales, revenue, stats)</li>
  <li>🎨 Modern React UI (with Ant Design or Material UI)</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<h3>Frontend</h3>
<ul>
  <li>React / Vite</li>
  <li>React Router</li>
  <li>Ant Design (UI components)</li>
  <li>Axios</li>
</ul>

<h3>Backend</h3>
<ul>
  <li>Node.js / Express</li>
  <li>MongoDB + Mongoose (or your DB)</li>
  <li>JWT Authentication</li>
  <li>CORS, Dotenv</li>
</ul>

<h2>📂 Project Structure</h2>
<pre>
ecommerce-admin/
 ├── frontend/   # React app
 └── backend/    # Node.js API
</pre>

<h2>⚡ Getting Started</h2>
<p><b>1️⃣ Clone the repo</b></p>
<pre>
git clone https://github.com/&lt;your-username&gt;/ecommerce-admin.git
cd ecommerce-admin
</pre>

<p><b>2️⃣ Setup Frontend</b></p>
<pre>
cd frontend
npm install
npm run dev   # start React app
</pre>

<p><b>3️⃣ Setup Backend</b></p>
<pre>
cd backend
npm install
npm run dev   # start Node.js server
</pre>

<h2>🔧 Environment Variables</h2>
<p>In <code>backend/.env</code> create:</p>
<pre>
PORT=5000
MONGO_URI=your_mongo_db_url
JWT_SECRET=your_secret_key
</pre>
